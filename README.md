# 夸夸学习 AI（KuaKua AI）

晴幂科技面向超级个体打造的实战学习平台。用户在 12 周内，用同一个真实项目走完战略、市场调研、产品、品牌体验、AI 技术与发布、商业化、运营系统与出海，最终形成一门能够上线、成交、交付、复盘和全球化验证的真实生意。

## 当前版本

- 8 个阶段、32 节实战课、24 次核心书精读（23 本独立书目），全部包含讲义、案例、AI 陪练、视频、练习、交付物和一手资料入口。
- 新增 YC 客户证据、Jason Cohen 商业真实性、37signals / Shape Up 有边界交付、Tiago Forte PARA 知识复利四套实践框架，并映射到具体课节与交付物。
- 新增个人公司工作台：当前项目、经营责任区、可复用资源、证据与资产四区，让每次学习都沉淀为下一次可调用的模板、SOP 或案例。
- 出海模块覆盖国家选择、本地化、跨境定价支付、税务与数据合规问题发现、渠道冷启动和单市场试航。
- OPC 链主总纲贯穿产品全流程；每节 AI 陪练统一使用可验收任务合同：角色、目标、受众、输入、约束、步骤、输出、验收。
- 晴幂知识伙伴“小晴”：每日夸赞、知识值、七级成长形态与完整产品能力图。
- 每课保存作品说明和可选链接；只有提交合格证据才计入课节、阶段、成长地图与毕业成熟度。
- 生产环境提供服务端注册、登录、HttpOnly 会话和平台管理员权限；localhost 继续保留学员、成长教练、平台管理员三类演示角色。
- 生产管理员可跨设备审核付款申请并生成企业兑换码；localhost 管理员可调整本机演示账号角色和状态。
- 新增会员体系：免费账号可浏览完整课程地图并学习“核心概念、学透方法”；AI 陪练、本地实作和作品提交需要有效会员。PRO 月付 ¥29、年付 ¥299，每自然月含 100 次 AI 陪练；Max 月付 ¥99、年付 ¥999，AI 工具不限量。
- 新增晴幂科技企业收款码、人工付款申请与管理员到账审核；企业客户可按购买席位领取一次性兑换码，每码开通六个日历月 PRO，平台仅保存兑换码 SHA-256 指纹。
- 桌面与移动端响应式界面；320–430px 已纳入独立布局验收，课节阅读器采用移动端全屏阅读。界面、课程地图与通用方法预览支持中、英、西、印地、阿五语，完整课程正文目前为简体中文。

## 生产服务与安全边界

线上前端部署在 `https://happykua.com/kuakua-ai/`，会员 API 部署在 `https://www.happykua.com/kuakua-ai-api/`。生产账号、会话、订单、会员权益、AI 次数和企业码核销全部由服务端数据库裁决；密码使用带随机盐的 PBKDF2，浏览器会话使用 `HttpOnly; Secure; SameSite=Lax` Cookie，会话 Token 与兑换码在数据库中只保存不可逆指纹。管理员权限、订单金额和权益发放均在服务端验证。

当前付款方式是正式可用的“企业收款码 + 人工到账审核”：用户扫码付款、提交付款人和交易凭证号，管理员必须在公司的真实收款后台核对到账后批准，服务端才会开通权益。它不是微信支付/支付宝商户 API 的自动回调模式，不能仅凭用户填写的信息自动确认到账。

课程学习记录、作品草稿、XP 与伙伴成长仍保存在当前浏览器 `localStorage`，尚未跨设备同步；生产会员权限不会读取或信任这些本地数据。生产 AI 陪练已连接 DeepSeek `deepseek-v4-flash`，由服务端完成会员核权、次数预占、失败回滚和结构化结果校验；平台不保存用户材料、提示词或模型回答。localhost / `127.0.0.1` 继续使用完全隔离的本地演示账号、会员钱包、测试兑换码和本地 AI 预览，不会写入生产数据库。

后端实现、配置、接口与部署说明见 `server/README.md`。

## 本地运行

```bash
npm ci
npm run dev
```

生产构建：

```bash
npm run build
```

完整发布验收（自动启动独立预览并运行链接、桌面、手机、五语和迁移测试）：

```bash
npm run verify
```

`https://happykua.com/kuakua-ai/`
