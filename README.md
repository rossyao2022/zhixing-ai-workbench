# 知行 AI · 学习与工作成长平台原型

基于项目 PRD、访谈逐字稿、需求评审材料、设计图，以及在线课程原型整合完成的第一版可交互桌面原型。

## 本地启动

```bash
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:5173/`。

生产构建：

```bash
npm run build
```

## 演示故事线

- 第一次上课：报名短信 → 激活账号 → 学习首页 → 进入课堂 → 工具免登录 → 生成作品。
- 课后复习：课程续播、达到 90% 自动完课、课程市场筛选与积分兑换。
- AI 工作台：注册后即可使用，包含今日重点、工作状态、判断依据、活动时间线与数据来源；系统会随着学习和使用逐步理解用户。
- 机构管理员：组织概览、学员与班级、批量开户、学习与工具用量、操作日志；数据范围仅限所属组织。
- 平台运营：全局组织、课程、工具、权益包、积分账本、对账、角色权限与操作日志。

后台功能包含课程上下架、工具维护状态、学员冻结/解冻、积分人工调整、对账差异处理、敏感权限矩阵等可见交互。所有数据均为本地演示数据。

首次激活完成后，可通过顶部的“切换视图”体验上课准备、课后复习、工作台、机构管理和平台运营。当前版本使用示例数据，不连接真实账号、支付或外部工具。
